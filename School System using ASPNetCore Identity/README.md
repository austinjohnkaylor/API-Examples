# School System using ASP.NET Core Identity
A repository that contains a school system API that uses ASP.NET Core Identity for authentication and authorization.
## Pre-requisites
- .NET 8.0 SDK
- Visual Studio 2022, Visual Studio Code, or Rider
- Postman
- SQL Server container or SQL Server installed on your machine
- Docker Desktop or Podman if you are using SQL Server in container
